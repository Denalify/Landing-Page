# Missing Features — Denalify vs. Competitors

> Research based on public feature pages and comparisons of: Asana, Trello, ClickUp, Monday.com, Linear, Notion, Basecamp (as of 2025).
> Use this file to prioritize the product roadmap.

---

## 🔴 HIGH Priority
> Present in 3+ major competitors. High user expectation — missing these creates friction in conversion.

| Feature | Competitors that have it | Notes |
|---|---|---|
| **Workflow automations** (if-this-then-that rules) | Monday, ClickUp, Asana, Zapier | Automatically move tasks, send notifications, change fields on trigger. Monday and ClickUp offer this even on mid-tier plans. |
| **Time tracking (built-in)** | ClickUp, Asana (via integration), Toggl/Harvest integrations everywhere | Teams expect to log hours directly on tasks. Currently requires a 3rd-party tool. |
| **Goals / OKR tracking** | ClickUp, Asana (Advanced+), Monday | Link tasks to measurable goals. Important for PM/leadership adoption. |
| **Recurring tasks** | Asana, ClickUp, Monday, Notion | Set tasks to repeat daily/weekly/monthly. Very common user request. |
| **Custom fields on tasks** | Asana, ClickUp, Monday | Add priority, status, score, custom text/dropdown/number fields to tasks. |

---

## 🟡 MEDIUM Priority
> Present in 2 competitors or valuable for specific user segments (tech teams, agencies).

| Feature | Competitors that have it | Notes |
|---|---|---|
| **AI features** (task generation, summaries, auto-fill) | ClickUp AI, Asana AI, Notion AI, Monday AI | Growing user expectation. Could differentiate if done well (e.g. "generate sprint from project description"). |
| **Docs / Wiki / Knowledge base** | ClickUp Docs, Notion, Basecamp | Keep project documentation alongside tasks. Reduces context switching. |
| **Whiteboard / mind map view** | ClickUp, Notion, Miro (integration) | Visual brainstorming linked to tasks. Popular with creative teams. |
| **Guest / external collaborator accounts** | Asana, ClickUp (Business+), Linear | Invite clients or contractors with restricted access. Important for agencies. |
| **Intake forms** (task creation via form) | ClickUp, Asana, Monday | Let external people submit requests that become tasks. Great for support/ops teams. |
| **Sprints / Cycles** | Linear (Cycles), Jira (Sprints), ClickUp | Structured iteration planning for dev teams. Linear's implementation is particularly well-regarded. |
| **Portfolio / multi-project view** | Asana (Advanced+), Monday | See status across all projects in one view. Important for managers/PMs. |

---

## 🟢 LOW Priority
> Niche or enterprise-only features. Worth adding eventually but not blockers for most users.

| Feature | Competitors that have it | Notes |
|---|---|---|
| **Resource management / Capacity planning** | Asana (Advanced+), Monday (Pro+) | See who is over/under-allocated across projects. Enterprise-focused. |
| **Native calendar view** | Asana, ClickUp, Monday | Denalify currently has Calendar *integration* but not a full built-in calendar view showing tasks. |
| **Mobile apps (iOS / Android)** | All major competitors | Critical for mainstream adoption. Web-only limits use cases significantly. |
| **Offline mode** | ClickUp (limited), Notion | Work without internet connection, sync when reconnected. |
| **Import from competitors** | ClickUp (import from Asana/Trello/Jira), Monday | One-click migration lowers switching cost. Strong acquisition lever. |
| **Time zone management** | Asana, Monday (Enterprise) | Show deadlines in each user's local timezone. Important for distributed teams. |
| **Custom branding / white-label** | ClickUp (Enterprise), Monday (Enterprise) | Remove Denalify branding for agency/reseller use cases. |
| **SIEM integration** (audit log export) | Asana (Enterprise+) | Push audit logs to Splunk/DataDog. Compliance requirement at large enterprises. |

---

## 💡 Denalify Unique Advantages (do NOT lose these)

These are features where Denalify currently leads — protect and market them:

- **Discord integration on Free plan** — no competitor offers this natively
- **Flat per-workspace pricing** — massive cost advantage for teams > 5 people vs. per-user pricing
- **Multiple UI themes** (modern dark, standard dark, light) — only Linear offers comparable dark-first UI
- **Enforce 2FA organisation-wide** — unique even at Team tier; competitors require Enterprise
- **35-member free plan** — most generous among competitors (Monday = 2 seats, Asana = 15)
